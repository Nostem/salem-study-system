<div style="font-size:13px;color:#9ca3af;margin-bottom:14px;line-height:1.7;">
<strong>Given:</strong><br>
Which of the following describes the interface between the Reactor Trip Handles on 2CC2 and the Reactor Protection System?<br><br>
Turning either Reactor Trip Handle to the trip position is designed to operate <span class="blank">___</span>.
</div>

<div style="margin-bottom:14px;">
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>A.</strong> the UV trip ONLY for Reactor Trip AND Reactor Trip Bypass breakers.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>B.</strong> the shunt trip ONLY for Reactor Trip AND Reactor Trip Bypass breakers.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>C.</strong> BOTH the shunt trip and UV trip for Reactor Trip AND Reactor Trip Bypass breakers.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>D.</strong> BOTH the shunt trip and UV trip for Reactor Trip breakers, and the shunt trip ONLY for the Reactor Trip Bypass breakers..</div>
</div>

<div style="padding:8px 12px;background:#052e16;border-left:3px solid #22c55e;border-radius:0 4px 4px 0;margin-bottom:10px;color:#c8cdd5;"><strong style="color:#22c55e;">✓ C. Correct.</strong> <em>Explanation of Answers (verbatim from source):</em> Salem has 2 Reactor Trip Handles/Switches. Either switch operates BOTH the UV and shunt trips for BOTH the reactor trip breakers and bypass breakers. The distracters are plausible because: 1) an automatic reactor trip ONLY actuates the UV trip; 2) manually tripping the reactor trip breakers from the control console ONLY actuates the shunt trip.</div>
