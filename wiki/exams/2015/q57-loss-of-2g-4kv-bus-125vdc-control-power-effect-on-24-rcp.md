<div style="font-size:13px;color:#9ca3af;margin-bottom:14px;line-height:1.7;">
<strong>Given:</strong><br>
Given the following conditions:<br>
&bull; The control room receives Auxiliary Typewriter alarm point 0676, 2G 4KV GROUP BUS LOSS 125 VDC CONTROL PWR.<br>
&bull; An operator investigates and reports 125 VDC breaker 2BDC1AX12, 2G 4KV Bus Control Power Supply (Reg) tripped.<br><br>
Which of the following identifies the effect, if any, this will have on 24 RCP 4KV breaker?<br><br>
If 24 RCP is running it will...
</div>

<div style="margin-bottom:14px;">
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>A.</strong> trip immediately.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>B.</strong> continue to run but will not trip if required.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>C.</strong> trip if a RPS trip signal is subsequently developed, but would not be able to be re-started if directed.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>D.</strong> continue to run and be unaffected as emergency control power from the alternate control power supply will automatically be provided.</div>
</div>

<div style="padding:8px 12px;background:#052e16;border-left:3px solid #22c55e;border-radius:0 4px 4px 0;margin-bottom:10px;color:#c8cdd5;"><strong style="color:#22c55e;">✓ B. Correct.</strong> <em>Explanation of Answers (verbatim from source):</em> 55.41.b(8) 4KV Group bus control power is supplied from the DC electrical system. The alternate DC supply does not automatically transfer to supply DC control power to the bus, it must be manually transferred when the normal supply is lost. 4 KV breakers cannot be tripped remotely without 125VDC available to energize trip coil. A is incorrect because there is no power to energize the trip coil, plus no trip signal would be present. B is correct because it would not trip if required (different from A is "immediate" vs. "subsequent"). D is incorrect because the control power swap is performed manually.</div>
