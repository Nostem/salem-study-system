<span style="color:#60a5fa;font-size:14px;font-weight:600;">Q43 — Plant Response When SI Occurs After a 4KV Vital Bus Undervoltage (SEC Sequencing)</span>
<span style="font-size:10px;padding:2px 8px;background:#0d1220;color:#6b7280;border-radius:3px;">013 K1.12 (RO 4.3 / SRO 4.3)</span>
</div>

<div style="font-size:13px;color:#9ca3af;margin-bottom:14px;line-height:1.7;">
<strong>Given:</strong><br>
Given the following conditions:<br>
&bull; Unit 2 is operating at 100% power when a turbine trip event and subsequent switchyard disturbance result in an undervoltage condition (&lt;70%) on the 2A &amp; 2C 4160 V vital buses.<br>
&bull; 2 minutes later, a Safety Injection signal is generated.<br><br>
Which of the following describes the plant response when the SI occurs?
</div>

<div style="margin-bottom:14px;">
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>A.</strong> EDG output breakers remain shut and safeguards loads sequence on each vital bus.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>B.</strong> EDG output breakers remain shut, blackout loads are stripped, then safeguards loads are sequenced on each vital bus.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>C.</strong> EDG output breakers open, blackout loads are stripped, EDG output breaker shuts, then only safeguards loads are sequenced on each vital bus.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>D.</strong> EDG output breakers open, blackout loads are stripped, EDG output breaker shuts, then safeguards and blackout loads are sequenced on each vital bus.</div>
</div>

<summary style="cursor:pointer;color:#60a5fa;font-size:12px;font-weight:600;padding:8px 0;">▶ Show Answer & Explanation</summary>
<div style="margin-top:10px;padding:16px;background:#0a0e17;border:1px solid #1a2035;border-radius:6px;font-size:12px;">
<div style="padding:8px 12px;background:#052e16;border-left:3px solid #22c55e;border-radius:0 4px 4px 0;margin-bottom:10px;color:#c8cdd5;"><strong style="color:#22c55e;">✓ C. Correct.</strong> <em>Explanation of Answers (verbatim from source):</em> 55.41.b(7) 2/3 4KV vital bus UV causes ALL 3 4KV vital buses to load in SEC MODE II BLACKOUT. This mode starts ALL EDGs and sequences BLACKOUT loads onto ALL vital buses. When the SI occurs, the SEC initiates a MODE III, which opens any running EDG breaker, strips whatever loads are energized, then sequences SAFEGUARDS loads onto ALL buses. Distracters are plausible based on determining the 2 buses 2A and 2C load individually in BLACKOUT based on the UV on those 2 buses only.</div>
