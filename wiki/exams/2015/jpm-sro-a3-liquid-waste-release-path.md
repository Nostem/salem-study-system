<strong>Initial Conditions:</strong><br>
Salem Unit 2 is on day 25 of a scheduled 45 day refueling outage.<br>
11 and 12 CCHX's are in service.<br>
21 CCHX is in service, 22 CCHX is removed from service and drained.<br>
All Unit 2 Circulators are O/S.<br>
Salem Unit 1 is operating at 75% power.<br>
12A Circulator is O/S for waterbox cleaning.<br>
The Non-Rad Waste Treatment System is in service performing a release, and must remain in service.<br>
Unit 1 is NOT in any active Tech Specs.<br>
12 CVCS Monitor Tank is in Recirc using 11 CVCS Monitor Tank Pump, and Chemistry has granted permission to release the tank with a minimum dilution flow rate of 100000 gpm.<br><br>
<strong>Initiating Cue:</strong><br>
You are the Unit 1 CRS. Select the release path for 12 CVCS Monitor Tank IAW S1.OP-SO.WL-0002, Attachment 2, Section 2.2 Release Verification <strong>AND</strong> provide marked up drawings of the flow path from 12 CVCS Monitor tank to its ultimate release point.
</div>

<strong style="color:#60a5fa;">Distractor Drawings:</strong><br>
<span style="color:#c8cdd5;">Per the JPM, drawings 205229-2, 205242-4, and 205342-5 are provided but are NOT needed for this flow path — they are included specifically so an incorrect alternate flow path could be selected. The applicant must reject them and route only through the in-service equipment.</span>
</div>

<div style="margin-top:12px;padding:10px;background:#052e16;border-left:3px solid #22c55e;border-radius:0 4px 4px 0;">
<strong style="color:#22c55e;">Key Decision Point:</strong><br>
<span style="color:#c8cdd5;">The discriminating determination is selecting the only viable release path from the available-equipment lineup. <strong>22 CCHX is removed from service and drained</strong>, so the release cannot route through it — it must go through <strong>21 CCHX</strong> (the only in-service Unit 2 Component Cooling Heat Exchanger). Because all Unit 2 Circulators are O/S, the dilution flow must come from a Unit 1 circulator via the Unit cross-connect; the path terminates at a running circulator discharge — <strong>12A and/or 12B CW Pump I/S</strong>. Note 12A Circulator is O/S for waterbox cleaning, so 12B (and/or 12A if restored) provides the &ge; 100000 gpm minimum dilution flow Chemistry granted. Selecting any path through 22 CCHX or an out-of-service circulator fails the task.</span>
</div>
