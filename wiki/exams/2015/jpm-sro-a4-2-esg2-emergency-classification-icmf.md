<div style="margin-top:12px;padding:10px;background:#052e16;border-left:3px solid #22c55e;border-radius:0 4px 4px 0;">
<strong style="color:#22c55e;">Key Decision Point:</strong><br>
<span style="color:#c8cdd5;">The discriminating element is selecting <strong>RB3.L (Loss of the RCS Boundary)</strong> from the EAL Description Table for the ESG-2 scenario. RB3.L is a single RCS-barrier <strong>Loss</strong>, which classifies as an <strong>ALERT</strong> (the classification escalates above Alert only when multiple barriers degrade — a single barrier loss, whether Potential or full Loss, remains an Alert). Description of Event = "Loss of the Reactor Coolant System Boundary." Unlike the ESG-1 variant, ICMF Section III is checked <strong>IS</strong> because a radiological release IS in progress (the lost RCS boundary path passes coolant to the environment). Section IV wind speed/direction is retrieved from SPDS. The two regulatory time-critical clocks are: (1) <strong>15 minutes from event recognition to ALERT declaration</strong>, and (2) <strong>15 minutes from declaration to ICMF delivery to the Primary Communicator</strong>. Missing either 15-minute window fails the task.</span>
