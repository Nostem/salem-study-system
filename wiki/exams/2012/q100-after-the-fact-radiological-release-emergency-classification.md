<span style="color:#60a5fa;font-size:14px;font-weight:600;">Q100 — After-the-Fact Radiological Release Emergency Classification</span>
<span style="font-size:10px;padding:2px 8px;background:#0d1220;color:#6b7280;border-radius:3px;">G2.4.29 (RO 3.1 / SRO 4.4)</span>
</div>

<div style="font-size:13px;color:#9ca3af;margin-bottom:14px;line-height:1.7;">
<strong>Given:</strong><br>
Given the following conditions:<br><br>
- 22 CVCS Monitor Tank was released to the Delaware River earlier this shift.<br>
- The release was secured 2 hours ago during the performance of S2.OP-SO.WL-0002, Radioactive Release from 22 CVCS Monitor Tank.<br>
- During a sample review after the release was secured, the Chemistry Department recognized that a Radioactive Liquid Release to the Delaware River was performed with an isotopic concentration which exceeded the ECG EAL RU1.3 Unusual Event threshold of 2X the ODCM for &gt;60 minutes.<br><br>
Which of the following describes how this should be addressed?
</div>

<div style="margin-bottom:14px;">
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>A.</strong> Initiate a non-emergency one hour report for this After-the-Fact event.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>B.</strong> Notify the NJ DEP within one hour of the report by Chemistry Department that the release rate exceeded the ODCM.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>C.</strong> Declare an Unusual Event based on exceeding the EAL at the time of the event, then terminate the UE because the EAL threshold is no longer being exceeded.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>D.</strong> Declare an Unusual Event based on exceeding the EAL at the time of the event, then retract the UE because the EAL threshold was NOT exceeded when the declaration was made.</div>
</div>

<details>
<summary style="cursor:pointer;color:#60a5fa;font-size:12px;font-weight:600;padding:8px 0;">▶ Show Answer &amp; Explanation</summary>
<div style="margin-top:10px;padding:16px;background:#0a0e17;border:1px solid #1a2035;border-radius:6px;font-size:12px;">
<div style="padding:8px 12px;background:#052e16;border-left:3px solid #22c55e;border-radius:0 4px 4px 0;margin-bottom:10px;color:#c8cdd5;"><strong style="color:#22c55e;">✓ A. Correct.</strong> Salem ECG, Introduction and Usage, Section 8.6, Conditions Discovered After-the-Fact, describes an after-the-fact event as an event that exceeded an EAL threshold and was not recognized at the time of occurrence but is identified greater than one hour after the conditions has occurred and the condition no longer exists. The stem identifies that the liquid release was terminated 2 hours ago, which terminates the release exceeding the ODCM. After the Fact events that occur will be assessed and evaluated to ensure that no EAL currently applies. An emergency declaration is NOT required and a non-emergency One-Hour Report should be initiated. The NJ DEP notification is required for spills, not discharges normally performed.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ B.</strong> The NJ DEP notification is required for spills, not discharges normally performed; this was a release performed per procedure, so the NJ DEP one-hour notification is not the required action.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ C.</strong> Declaring an Unusual Event is incorrect — this is an after-the-fact event (identified &gt;1 hour after the conditions occurred and the condition no longer exists); an emergency declaration is NOT required, so there is no UE to declare and then terminate.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ D.</strong> Declaring and then retracting a UE is incorrect — for an after-the-fact condition that no longer exists, no emergency declaration is required in the first place; a non-emergency One-Hour Report is initiated instead.</div>
