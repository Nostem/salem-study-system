<div style="font-size:13px;color:#9ca3af;margin-bottom:14px;line-height:1.7;">
<strong>Given:</strong><br>
Of the following, which identifies who will APPROVE the installation of a Temporary Configuration Change IAW CC-AA-112-1001, Attachment 5, Temporary Configuration Change Package Installation?
</div>

<div style="margin-bottom:14px;">
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>A.</strong> Plant Operations Review Committee (PORC) Chairman.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>B.</strong> System Manager(s) for affected system(s).</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>C.</strong> Operations Manager.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>D.</strong> Shift Manager / CRS.</div>
</div>

<summary style="cursor:pointer;color:#60a5fa;font-size:12px;font-weight:600;padding:8px 0;">▶ Show Answer &amp; Explanation</summary>
<div style="margin-top:10px;padding:16px;background:#0a0e17;border:1px solid #1a2035;border-radius:6px;font-size:12px;">
<div style="padding:8px 12px;background:#052e16;border-left:3px solid #22c55e;border-radius:0 4px 4px 0;margin-bottom:10px;color:#c8cdd5;"><strong style="color:#22c55e;">✓ D. Correct.</strong> CC-AA-112 and associated T&amp;RM delineate who approves Temporary Configuration changes. A is incorrect because the System Manager (SM) performs a review of the TCCP. The SM is also responsible for reviewing the limited duration requirements for temporary changes installed per Maintenance Rule (a)(4). SM is responsible for assisting the RE with post installation testing. SM is also responsible for ensuring that TCCP Extended Installation Justification is approved. A is incorrect because the PORC is a multi-disciplined committee responsible for review of activities that have the potential to affect nuclear safety. C is incorrect because the Ops Manager is not required to approve TCCs.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ A.</strong> A is incorrect because the PORC is a multi-disciplined committee responsible for review of activities that have the potential to affect nuclear safety, not the approval authority for TCC installation.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ B.</strong> B is incorrect because the System Manager (SM) performs a review of the TCCP (and reviews limited duration requirements, assists with post installation testing, ensures Extended Installation Justification is approved) but is not the approval authority for installation.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ C.</strong> C is incorrect because the Ops Manager is not required to approve TCCs.</div>
