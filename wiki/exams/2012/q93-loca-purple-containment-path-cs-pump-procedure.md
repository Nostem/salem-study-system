<span style="color:#60a5fa;font-size:14px;font-weight:600;">Q93 — LOCA PURPLE Containment Path CS Pump Procedure</span>
<span style="font-size:10px;padding:2px 8px;background:#0d1220;color:#6b7280;border-radius:3px;">G2.4.22 (RO 3.6 / SRO 4.4)</span>
</div>

<div style="font-size:13px;color:#9ca3af;margin-bottom:14px;line-height:1.7;">
<strong>Given:</strong><br>
Given the following conditions:<br><br>
- Unit 2 has experienced a LOCA.<br>
- 21 RHR pump has been C/T for the last 2 days.<br>
- Containment pressure is 14 psig and rising slowly.<br>
- 22 RHR pump trips after performing Safeguards Reset actions in EOP-LOCA-1, Loss of Reactor Coolant.<br>
- The CRS transitions to LOCA-5, Loss of Emergency Recirculation.<br>
- The STA reports a valid PURPLE path on Containment Environment with containment pressure at 15 psig and rising slowly, and no higher PURPLE or any RED paths present.<br><br>
Which of the following describes how the CRS should use Containment Spray pumps?<br><br>
The CRS should start/stop Containment Spray pumps in…..
</div>

<div style="margin-bottom:14px;">
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>A.</strong> EOP-FRCE-1, Response to Excessive Containment Pressure, because Containment Spray pumps will not auto start with the SECs reset.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>B.</strong> EOP-FRCE-1 because at least one Containment Spray pump is required to be running whenever containment pressure is &gt;15 psig.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>C.</strong> EOP-LOCA-5 to establish minimum required CS flow in order to conserve RWST inventory.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>D.</strong> EOP-LOCA-5 since FRPs are not in effect when LOCA-5 is in effect.</div>
</div>

Correct.</strong> The transition to FRCE-1 is required upon a valid PURPLE path (15 psig containment). A is incorrect because FRCE-1 specifically asks if LOCA-5 is in effect, and if so, direct CS pumps to be operated IAW LOCA-5. B is incorrect because of the above reason, and additionally, using the table found in LOCA-5 as the bases, there are conditions with cont press&gt;15 psig that NO CS pumps will be directed to be started. C is correct. D is incorrect because FRPs are in effect after the transition out of TRIP-1, and there is no direction to suspend FRPs either in LOCA-1 or LOCA-5.</div>
