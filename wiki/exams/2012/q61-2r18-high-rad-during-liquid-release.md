<span style="color:#60a5fa;font-size:14px;font-weight:600;">Q61 — 2R18 High Rad During Liquid Release</span>
<span style="font-size:10px;padding:2px 8px;background:#0d1220;color:#6b7280;border-radius:3px;">073 K3.01 (RO 3.6 / SRO 4.2)</span>
</div>

<div style="font-size:13px;color:#9ca3af;margin-bottom:14px;line-height:1.7;">
<strong>Given:</strong><br>
Given the following conditions:<br><br>
- Salem Unit 1 is operating at 100% power, with no equipment out of service.<br>
- Salem Unit 2 is in MODE 5, during a return from a refueling outage.<br>
- Unit 2 is performing a normal Liquid Release from 21 CVCS Monitor Tank to Unit 1 CW IAW S2.OP-SO.WL-0001. Release of Radioactive Liquid Waste from 21 CVCS monitor tank.<br>
- The Radwaste Overboard Discharge Flow Recorder 2FR-1064 is OPERABLE.<br>
- The 2R18 Liquid Waste Disposal and the 2R41D Plant Vent Release Rate monitors are OPERABLE.<br>
- After commencing the release, the field operator is recording the Initial Release Data.<br>
- When recording the 2R18 reading, it reads 10 E6 cps.<br>
- The 2R18 red alarm light is lit on the 104 panel.<br>
- The 2WL51 Liquid Release Stop Valve indicates OPEN in the control room.<br><br>
Which of the following describes what these indications mean, and how the operating crew should proceed?
</div>

<div style="margin-bottom:14px;">
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>A.</strong> The 2R18 is reading below the actual alarm setpoint. Continue with the liquid release and reset the alarm light at the 104 Panel.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>B.</strong> With the 2FR-1064 and 2R41D OPERABLE, block the 2R18 input to the 2WL51 on 2RP1 prior to the time delay timing out and continue the liquid release.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>C.</strong> The 2WL51 should have immediately automatically closed on the 2R18 high radiation alarm. The NCO in the control room should shut 2WL51.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>D.</strong> The 2WL51 should have immediately automatically closed on the 2R18 high radiation alarm. The NEO should shut 2WL51 locally.</div>
</div>

<details>
<summary style="cursor:pointer;color:#60a5fa;font-size:12px;font-weight:600;padding:8px 0;">▶ Show Answer &amp; Explanation</summary>
<div style="margin-top:10px;padding:16px;background:#0a0e17;border:1px solid #1a2035;border-radius:6px;font-size:12px;">
<div style="padding:8px 12px;background:#052e16;border-left:3px solid #22c55e;border-radius:0 4px 4px 0;margin-bottom:10px;color:#c8cdd5;"><strong style="color:#22c55e;">✓ C. Correct.</strong> 55.41.b(13) 6.82E5 cps is the ALARM setpoint which will automatically shut the 2WL51 (S2.IC-CC.RM-0028). The current reading is above the setpoint at which the 2WL51 should have automatically shut, and the NCO should shut the valve remotely. The red alarm light for high radiation indicates the 2WL51 should have shut, memorization of alarm setpoint is not necessary. Additionally, S2.OP-SO.WL-0001 for releasing the tank, Step 5.5.9, says if the 2R18 alarms, then the NEO is to inform the NCO to shut the 2WL51. There is no provision for closing the valve locally. There is no time delay for 2WL51 closure, nor is there any provision for releasing a hot tank or is there an expected spike.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ A.</strong> The current reading is above the setpoint at which the 2WL51 should have automatically shut; the 2R18 is NOT reading below the alarm setpoint. The release cannot be continued.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ B.</strong> There is no time delay for 2WL51 closure, nor is there any provision for releasing a hot tank.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ D.</strong> The NCO shuts the 2WL51 remotely from the control room; there is no provision for closing the valve locally.</div>
