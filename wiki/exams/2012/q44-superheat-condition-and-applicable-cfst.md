<span style="color:#60a5fa;font-size:14px;font-weight:600;">Q44 — Superheat Condition and Applicable CFST During LOCA</span>
<span style="font-size:10px;padding:2px 8px;background:#0d1220;color:#6b7280;border-radius:3px;">017 K5.03 (RO 0 / SRO 0)</span>
</div>

<div style="font-size:13px;color:#9ca3af;margin-bottom:14px;line-height:1.7;">
<strong>Given:</strong><br>
Given the following conditions:<br><br>
- A LOCA is in progress.<br>
- Operators have transitioned out of EOP-TRIP-1, Reactor Trip or Safety Injection.<br><br>
Which of the following indicates a superheat condition exists in the core, and what CFST is applicable?
</div>

<div style="margin-bottom:14px;">
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>A.</strong> 5 or more CETs &gt; 1200°F. RED path for Core Cooling.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>B.</strong> 5 or more CETs &gt; 1200°F. PURPLE path for Core Cooling.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>C.</strong> ALL CETs 650°F with RVLIS Full Range 35%. RED path for Core Cooling.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>D.</strong> ALL CETs 650°F with RVLIS Full Range 74%. PURPLE path for Core Cooling.</div>
</div>

<details>
<summary style="cursor:pointer;color:#60a5fa;font-size:12px;font-weight:600;padding:8px 0;">▶ Show Answer &amp; Explanation</summary>
<div style="margin-top:10px;padding:16px;background:#0a0e17;border:1px solid #1a2035;border-radius:6px;font-size:12px;">
<div style="padding:8px 12px;background:#052e16;border-left:3px solid #22c55e;border-radius:0 4px 4px 0;margin-bottom:10px;color:#c8cdd5;"><strong style="color:#22c55e;">✓ A. Correct.</strong> 55.41.b.(5,10) With CETs indicating &gt;1200°F …."this temperature indicates that most liquid inventory has already been removed from the RCS and that core decay heat is superheating steam in the core."(page 6) This is a FRCC RED path entry to FRCC-1 Response to Inadequate Core Cooling.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ B.</strong> B is incorrect because its priority (PURPLE) is wrong.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ C.</strong> The 2 distracters with CETs at 650 °F are wrong first because CFST Basis Doc, page 10 states that at least 5 CETs have to be &gt;700°F to indicate superheat is present at the core exit. With &lt;700°F there is still an entry into Core Cooling PURPLE path if RVLIS Full Range is &lt;39%. C is incorrect because of the lack of superheat and RVLIS level indicates PURPLE Path.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ D.</strong> D is incorrect because it is not indicated that superheat exists, and a YELLOW path not PURPLE path.</div>
