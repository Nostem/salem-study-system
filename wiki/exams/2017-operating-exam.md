# 2017 NRC Operating Exam

## Overview

- **Exam:** SALEM 2017 NRC Retake Exam — 15-01 ILOT (Section C only — simulator scenarios)
- **Revision Date:** 4-6-17 (Rev 01); approved 4-11-17
- **Facility:** Salem Units 1 & 2
- **Scope:** Simulator scenarios only — no JPMs re-administered
- **Simulator Scenarios:** 2 — ESG-7, ESG-8

This is a **retake** of the 15-01 ILOT operating exam. The original 2016 administration (JPMs + Section A/B/C) is documented in [[2016 NRC Operating Exam]]. Only the simulator portion was re-administered for the 2017 retake; the JPM batteries from the 2016 exam were not repeated.

**Scenario provenance (per the PDF revision summaries):**
- **ESG-7** — derived from 15-01 ILOT ESG-4 with malfunction substitutions for the 2017 retake. Removed: loss of 2A 460V bus, BAT pumps. Added: leaking PZR PORV, RC Loop RTD failure.
- **ESG-8** — developed from a 2014 Annual ESG-1418 for the 2017 retake.
