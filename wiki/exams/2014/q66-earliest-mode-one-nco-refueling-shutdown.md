<span style="font-size:10px;padding:2px 8px;background:#0d1220;color:#6b7280;border-radius:3px;">2.1.2 (RO 4.1 / SRO 4.4)</span>

<div style="font-size:13px;color:#9ca3af;margin-bottom:14px;line-height:1.7;">
<strong>Given:</strong><br>
During a Unit 2 plant shutdown for refueling, which of the following is the EARLIEST point at which only ONE NCO is required to be in the Unit 2 control room IAW Salem Tech Specs Table 6.2-1, Minimum Shift Crew Composition, Salem Unit 2?
</div>

<div style="margin-bottom:14px;">
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>A.</strong> Mode 3.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>B.</strong> Mode 4.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>C.</strong> Mode 5.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>D.</strong> Mode 6.</div>
</div>

<details>
<summary style="cursor:pointer;color:#60a5fa;font-size:12px;font-weight:600;padding:8px 0;">▶ Show Answer &amp; Explanation</summary>
<div style="margin-top:10px;padding:16px;background:#0a0e17;border:1px solid #1a2035;border-radius:6px;font-size:12px;">
<div style="padding:8px 12px;background:#052e16;border-left:3px solid #22c55e;border-radius:0 4px 4px 0;margin-bottom:10px;color:#c8cdd5;"><strong style="color:#22c55e;">✓ C. Correct.</strong> Salem Tech Specs, Section 6.0, Admin Controls, page 6-5, Table 6.2-1. The requirements are the same regardless of Unit. Mode 5 is the earliest mode during a refueling shutdown at which only one NCO is required to be in the control room (the minimum shift crew composition is reduced for Modes 5 and 6 relative to Modes 1–4).</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ A.</strong> Mode 3 — In Modes 1, 2, 3, and 4 the minimum shift crew composition per Table 6.2-1 still requires more than one NCO; Mode 3 is not yet the point at which the requirement is reduced to one NCO.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ B.</strong> Mode 4 — Same as Mode 3; the Modes 1–4 minimum shift crew composition still applies and the reduced one-NCO requirement does not yet take effect.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ D.</strong> Mode 6 — The reduced one-NCO requirement is already in effect by Mode 5, so Mode 6 is not the EARLIEST point at which only one NCO is required.</div>
