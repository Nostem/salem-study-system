<strong>Given:</strong><br>
Which of the following indications is the ONLY one allowed to be used as part of the steps performed to verify natural circulation is occurring if the Core Exit Thermocouple Processing System becomes de-energized IAW 2-EOP-CFST-1 Critical Safety Function Status Trees?
</div>

<div style="margin-bottom:14px;">
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>A.</strong> Plant Computer readings.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>B.</strong> Subcooling Margin Monitor readings.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>C.</strong> Installed Control Room Class 1E readings.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>D.</strong> Safety Parameter Display System readings.</div>

<details>
<summary style="cursor:pointer;color:#60a5fa;font-size:12px;font-weight:600;padding:8px 0;">▶ Show Answer &amp; Explanation</summary>
<div style="margin-top:10px;padding:16px;background:#0a0e17;border:1px solid #1a2035;border-radius:6px;font-size:12px;">
<div style="padding:8px 12px;background:#052e16;border-left:3px solid #22c55e;border-radius:0 4px 4px 0;margin-bottom:10px;color:#c8cdd5;"><strong style="color:#22c55e;">✓ C. Correct.</strong> CET's are the primary indication of RCS temperature. The CET Processing system takes the input from all CET's, coverts it to a digital signal, and sends them to various places, including the Subcooling Margin Monitor, SPDS, and the eP-250 Computer. With the system (2 trains) deenergized, there is no CET indication to send anywhere. The only remaining indications for RCS temperature are provided via the Class 1E control console indications.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ A.</strong> The CET temperature indications normally provided on SPDS and Plant Computer are de-energized along with the CET Processing System — they receive their input from the CET Processing System, so they are unavailable. (Those systems are also exempt from 1E requirements.)</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ B.</strong> The Subcooling Margin Monitor receives its CET input from the CET Processing System; with that system de-energized, the Subcooling Margin Monitor CET indications are unavailable.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ D.</strong> SPDS receives its CET input from the CET Processing System; with that system de-energized, the SPDS CET indications are unavailable, and SPDS is exempt from 1E requirements.</div>
