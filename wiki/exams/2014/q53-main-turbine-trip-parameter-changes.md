<strong>Given:</strong><br>
Which of the following parameters will change in the direction indicated following a Main Turbine trip from 90% power, once new steady state conditions have been reached?
</div>

<div style="margin-bottom:14px;">
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>A.</strong> TAC system D/P will be lower.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>B.</strong> TAC system supply temp will be lower.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>C.</strong> TGA SW header pressure will be higher.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>D.</strong> Main Condenser Hotwell levels will be higher.</div>
</div>

<div style="padding:8px 12px;background:#052e16;border-left:3px solid #22c55e;border-radius:0 4px 4px 0;margin-bottom:10px;color:#c8cdd5;"><strong style="color:#22c55e;">✓ D. Correct.</strong> Hotwell levels will rise as the turbine trip initiates a Rx trip &gt;P-9, and the BF19s and 40's will shut on FW interlock. There will be no "goes out" from the hotwells, but it will still be receiving "goes in" from the Steam dump system from the Main steam system, and the SGs will be fed from the AFW pumps.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ A.</strong> Turbine aux cooling (TAC) system D/P is maintained at pre-set setpoint, and automatic valve will operate to maintain it, so actual D/P will not change based on heat load or flow.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ B.</strong> TAC system HX outlet is controlled at setpoint automatically, so the TAC supply temp will not change.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ C.</strong> TGA SW header pressure is regulated by ST1, which maintains downstream pressure of 80 psig, so it will modulate to maintain pressure stable.</div>
