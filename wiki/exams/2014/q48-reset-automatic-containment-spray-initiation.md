<span style="color:#60a5fa;font-size:14px;font-weight:600;">Q48 — Reset Automatic Containment Spray Initiation</span>
<span style="font-size:10px;padding:2px 8px;background:#0d1220;color:#6b7280;border-radius:3px;">026000A4.05 (RO 3.5 / SRO 3.5)</span>
</div>

<div style="font-size:13px;color:#9ca3af;margin-bottom:14px;line-height:1.7;">
<strong>Given:</strong><br>
Which of the following contains ONLY the action(s) and/or conditions REQUIRED to electrically reset an AUTOMATIC Containment Spray initiation?
</div>

<div style="margin-bottom:14px;">
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>A.</strong> Depress BOTH Reset Phase B PBs, then depress BOTH Reset Spray Actuation PBs at ANY containment pressure.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>B.</strong> Containment pressure &lt;15 psig. Depress BOTH Reset SI PBs, depress BOTH Reset Spray Actuation PBs.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>C.</strong> Containment pressure &lt;15 psig. Depress BOTH Reset Spray Actuation PBs.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>D.</strong> Depress BOTH Reset Spray Actuation PBs at ANY containment pressure.</div>
</div>

<details>
<summary style="cursor:pointer;color:#60a5fa;font-size:12px;font-weight:600;padding:8px 0;">▶ Show Answer &amp; Explanation</summary>
<div style="margin-top:10px;padding:16px;background:#0a0e17;border:1px solid #1a2035;border-radius:6px;font-size:12px;">
<div style="padding:8px 12px;background:#052e16;border-left:3px solid #22c55e;border-radius:0 4px 4px 0;margin-bottom:10px;color:#c8cdd5;"><strong style="color:#22c55e;">✓ D. Correct.</strong> Containment Spray actuation relays have retentive memory, which allows relays to be manually reset with an actuation signal still present. For this reason, B and C are incorrect because containment pressure is not required to be less than 15 psig. D is correct because BOTH trains of CS have to be reset, and electrically can be reset regardless of cont pressure.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ A.</strong> A is incorrect because Phase B is not required to be reset to reset Cont Spray.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ B.</strong> B is incorrect because containment pressure is not required to be less than 15 psig, and depressing Reset SI PBs is not required to reset Containment Spray.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ C.</strong> C is incorrect because containment pressure is not required to be less than 15 psig — the actuation relays have retentive memory and can be reset with the signal still present.</div>
