<span style="color:#60a5fa;font-size:14px;font-weight:600;">Q96 — Converting a TCCP to a Permanent Configuration Change</span>
<span style="font-size:10px;padding:2px 8px;background:#0d1220;color:#6b7280;border-radius:3px;">194001 G2.2.11 (RO 2.3 / SRO 3.3)</span>
</div>

<div style="font-size:13px;color:#9ca3af;margin-bottom:14px;line-height:1.7;">
<strong>Given:</strong><br>
A Temporary Configuration Change Package (TCCP) will be converted to a Permanent Configuration Change IAW CC-AA-112 Temporary Configuration Changes, and CC-AA-103 Configuration Change Control for Permanent Physical Plant Changes.<br><br>
Of the following choices, determine the only one which is NOT performed as part of the Design Change Process to convert the TCCP into a Permanent Configuration Change.
</div>

<div style="margin-bottom:14px;">
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>A.</strong> The implemented permanent configuration change must be accepted by Operations prior to closing the TCCP.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>B.</strong> The permanent configuration change Ops Acceptance date will be used as the TCCP removal date.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>C.</strong> Administrative controls associated with the TCCP will be removed.</div>
<div style="padding:10px 14px;border-left:3px solid #1a2035;margin-bottom:4px;font-size:12px;color:#c8cdd5;background:#0d1220;border-radius:0 4px 4px 0;"><strong>D.</strong> The Work Order to remove the TCCP will be cancelled.</div>
</div>

<details>
<summary style="cursor:pointer;color:#60a5fa;font-size:12px;font-weight:600;padding:8px 0;">▶ Show Answer &amp; Explanation</summary>
<div style="margin-top:10px;padding:16px;background:#0a0e17;border:1px solid #1a2035;border-radius:6px;font-size:12px;">
<div style="padding:8px 12px;background:#052e16;border-left:3px solid #22c55e;border-radius:0 4px 4px 0;margin-bottom:10px;color:#c8cdd5;"><strong style="color:#22c55e;">✓ D. Correct.</strong> When implementing a Design Change Package (DCP) to make a TCCP permanent, the removal work order for the TCCP must be completed, even if the only task is the removal of the TCCP tags, update of Operations TCC Tracking Log, and completion of referenced administrative controls and OWDs. This may be done in the DCP work order and the completion of the removal work order would reference the DCP work order, but the removal work order for the TCCP should NOT be cancelled. Therefore cancelling the removal Work Order is the action NOT performed.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ A.</strong> This action IS performed — the implemented permanent configuration change must be accepted by Operations prior to closing the TCCP. C is plausible if it is thought that the TCCP must be removed before the DCP is accepted, but acceptance prior to closing the TCCP is a required step.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ B.</strong> This action IS performed — the permanent configuration change Ops Acceptance date will be used as the TCCP removal date. B is plausible if it is thought that administrative controls would be transferred to the DCP.</div>
<div style="padding:8px 12px;border-left:3px solid #f87171;border-radius:0 4px 4px 0;margin-bottom:6px;color:#9ca3af;"><strong style="color:#f87171;">✗ C.</strong> This action IS performed — administrative controls associated with the TCCP (including completion of referenced administrative controls and OWDs) are addressed as part of the removal work order. It is therefore not the action that fails to be performed.</div>
