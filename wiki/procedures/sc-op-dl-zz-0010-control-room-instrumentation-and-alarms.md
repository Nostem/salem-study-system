# SC.OP-DL.ZZ-0010 — Control Room Instrumentation and Alarms

## Purpose

Station procedure governing the documentation and marking of inoperable control room instrumentation and alarms (status of indicators, recorders, and annunciators in the control room).

## Key Actions / Information

**Exam & operating coverage:**

<div class="callout callout-exam">
<div class="callout-label">Exam — 2012 Q80</div>
An instrument that is NOT credited by a Tech Spec (e.g., the PZR Cold Cal level channel LI-462, used only when RCS temperature is &lt;200&deg;F per S2.OP-IO.ZZ-0006) is not subject to a Tech Spec entry when it fails. The status of such an instrument is tracked per SC.OP-DL.ZZ-0010. <span class="hi-exam">Red translucent tape is used to identify an inoperable alarm</span>; an <span class="hi-exam">INFO sticker</span> is used on an instrument indication that is not associated with an inoperable alarm. With LI-462 indicating 0% at 100% power and no Tech Spec applicability, the correct action is to place an INFO sticker on LI-462.
</div>
