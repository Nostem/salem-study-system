# S2.OP-SO.PZR-0008 — Setting Pressurizer Spray Bypass Flow

## Purpose

System operating procedure for establishing the pressurizer spray bypass (continuous warming) flow around the main spray valves. The bypass keeps the spray line continuously warm so the spray nozzle is not thermally shocked when spray is demanded.

## Key Actions / Information

**Exam & operating coverage:**

<div class="callout callout-exam">
<div class="callout-label">Exam — 2015 Q39</div>
The PZR Spray Nozzle is protected from thermal shock during normal operation because <span class="hi-exam">a small amount of spray flow is bypassed around the PS1 and PS3 Spray Valves to keep the spray line continuously warm</span>. Spray bypass flow is set during startup while at NOT/NOP to ensure spray line temperature is &gt;500°F with both spray valves shut. <span class="hi-trap">Spray flow is NOT initiated when spray-line delta-T exceeds 320°F; control heater groups are SCR-controlled to maintain pressure on program and do not force spray flow.</span>
</div>
