# S2.OP-ST.DG-0002 — 2B Diesel Generator Surveillance Test

## Purpose

Surveillance test procedure for the 2B Emergency Diesel Generator. During a normal surveillance run the 2B EDG is paralleled to the 2B 4KV vital bus and loaded to a specified KW load.

## Key Actions / Information

**Exam & operating coverage:**

<div class="callout callout-exam">
<div class="callout-label">Exam — 2014 Q59</div>
With the 2B EDG paralleled to the 2B 4KV vital bus for a surveillance run at 2525 KW, placing the 2B-DF-GCP-1, 2B Diesel Gen Loading Switch in <span class="hi-exam">AUTO (ISOCR)</span> causes the generator to attempt to pick up large +/- VAR loading because it is attempting to control grid voltage. There is no SPT-to-EDG control interlock, so the EDG will <span class="hi-exam">trip on either reverse power or output breaker over-current</span> — it will NOT speed up.
</div>
