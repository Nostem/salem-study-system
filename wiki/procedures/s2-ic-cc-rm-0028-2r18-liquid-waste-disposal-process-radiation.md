# S2.IC-CC.RM-0028 — 2R18 Liquid Waste Disposal Process Radiation Monitor

> ⚠️ DRAFT — Reconstructed from exam materials

## Purpose

Calibration / setpoint procedure for the 2R18 Liquid Waste Disposal process radiation monitor, which monitors the radioactive liquid waste discharge path and automatically isolates the release on high radiation.

## Key Actions / Information

<div class="callout callout-exam">
<div class="callout-label">Exam — 2012 Q61</div>
The <span class="hi-exam">2R18 high-radiation ALARM setpoint is 6.82E5 cps</span>, which <span class="hi-exam">automatically shuts the 2WL51 Liquid Release Stop Valve</span>. If the 2R18 red high-radiation alarm light is lit on the 104 panel and 2WL51 indicates OPEN, the 2WL51 should have already auto-closed — the NCO shuts the valve remotely from the control room. <span class="hi-trap">There is no time delay for 2WL51 closure, no provision for closing the valve locally, and no provision for releasing a "hot" tank.</span>
</div>
