# SC.OP-AB.CR-0003 — Control Room Habitability

## Purpose

Abnormal procedure for a loss of control room habitability (e.g., a toxic gas release on site). For a toxic-gas event it directs the control room evacuation to be performed using AB.CR-0001 (Control Room Evacuation), but it does not itself contain the field actions for establishing local plant control.

## Key Actions / Information

**Exam & operating coverage:**

<div class="callout callout-exam">
