# CC-AA-112 — Temporary Configuration Changes

## Purpose

Administrative procedure governing the process for controlling temporary design/configuration changes at Salem and Hope Creek stations.

## Key Requirements

- **CRS** is responsible for approving installation of Temporary Configuration Changes (TCCs)
- Design Engineering Manager is an approver in the development of the TCCP but does not approve installation
- TCCs established during maintenance activity (MR90s) are not subject to a 50.59 review provided:
  - The MR90 is in direct support of maintenance
  - The MR90 will be installed for no more than 90 days at power
- TCCs installed greater than 90 days require a 50.59 review

## Converting a TCCP to a Permanent Configuration Change

**Exam & operating coverage:**

<div class="callout callout-exam">
<div class="callout-label">Exam — 2014 Q96</div>
When a TCCP is converted to a Permanent Configuration Change via a Design Change Package (DCP, CC-AA-103), the <span class="hi-exam">removal Work Order for the TCCP must be COMPLETED, NOT cancelled</span> — even if its only task is removing the TCCP tags, updating the Operations TCC Tracking Log, and completing referenced administrative controls and OWDs. (The completion may be done in the DCP work order, with the removal WO referencing the DCP work order.) Other required steps: <span class="hi-exam">the implemented permanent change must be accepted by Operations before the TCCP is closed</span>, and the <span class="hi-exam">Ops Acceptance date is used as the TCCP removal date</span>. <span class="hi-trap">Trap: cancelling (rather than completing) the removal Work Order is the action that is NOT performed.</span>
</div>

## Approval of TCC Installation

**Exam & operating coverage:**

<div class="callout callout-exam">
<div class="callout-label">Exam — 2012 Q96</div>
Per CC-AA-112-1001, Attachment 5 (Temporary Configuration Change Package Installation), the <span class="hi-exam">Shift Manager / CRS</span> APPROVES installation of a Temporary Configuration Change. <span class="hi-trap">Trap: the System Manager only performs a review of the TCCP (and reviews limited-duration / Maintenance Rule (a)(4) requirements, assists the RE with post-installation testing, and ensures any Extended Installation Justification is approved) — the SM does not approve installation.</span> The PORC reviews activities with the potential to affect nuclear safety but is not the installation approver, and the Ops Manager is not required to approve TCCs.
</div>
