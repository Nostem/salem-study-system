# SECs (Safeguards Equipment Control System) — UFSAR enrichment gaps

- SEC per-load sequencing step time delays (the discrete time-delay values, in seconds, at which each safeguards load is sequenced onto the bus) — checked UFSAR §7.3.1.1.10 (and modes .1–.5), §8.3, TS Table 3.3-4 (Amend 310), existing exam/scenario callouts; the UFSAR describes the prescribed-order/time-delay loading qualitatively but gives no per-step time values. Only the CFCU low-speed start delay ("approximately 15 to 20 seconds" coastdown, §7.3.1.1.10.1) and CS pump start ("approximately 20 seconds following an accident", §7.3.1.1.10.3) are stated.
- SEC controller-to-VIB power mapping and equipment-to-vital-bus assignment table (which specific pumps/valves each A/B/C SEC commands) — checked UFSAR §7.3.1.1.10, §7.3.2; the UFSAR states each vital bus control is independent and equipment is powered from the respective 4 kV/460 V buses, but the detailed equipment-to-bus mapping comes only from the existing exam callouts (e.g. 2016 Q39, 2016 Q19), not the UFSAR. Recorded as sourced from callouts, not UFSAR.
