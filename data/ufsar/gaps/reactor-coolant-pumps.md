# Gaps — reactor-coolant-pumps (catalog system 003)

K/A-index topics not answered by UFSAR §5.5.1, TS 3/4.4, or the existing exam/JPM/scenario callouts. Recorded honestly per the ingestion guide — never fabricated.

- 003 A1.04 / A3.05 / A4.03 / K1.01 / K2.03 / K6.03 — RCP lube-oil and bearing lift-oil pump system (oil reservoir levels, lift-oil/lube-oil pump motor controls and power supplies, lift-oil pump details) — UFSAR §5.5.1 describes only that low oil levels in the lube-oil reservoirs alarm in the control room (§5.5.1.3.4) and that the bearings are oil-lubricated (§5.5.1.2); the lift-oil/lube-oil pump arrangement, controls, and power supplies are not in §5.5.1. The 500 psig lift-oil start interlock is captured in the existing 2015 Q31 callout. Checked UFSAR §5.5.1, TS 3/4.4, S2.OP-SO.RC-0001 references, existing callouts; no further sourced detail found in-section.
- 003 A1.13 / A4.09 — RCP motor current normal/expected value and indication — UFSAR §5.5.1 notes high current leads to Electrical Protection System trip (§5.5.1.3.4) but gives no normal motor-current value or control-room indication detail. Charging/seal-flow demand effects are in the existing 2014 Q40 callout. Checked UFSAR §5.5.1, TS 3/4.4, existing callouts; no sourced value found.
- 003 A1.10 — RCP standpipe normal level value — UFSAR §5.5.1 does not give a standpipe level; standpipe behavior is covered by existing callouts (2020 Q28, 2022 Sim-d JPM) but no numeric normal level is stated. Checked UFSAR §5.5.1, TS 3/4.4, existing callouts; no sourced numeric value found.
- 003 K2.01 / K2.04 — RCP motor power-supply bus identity (4KV group bus assignments) and the specific containment isolation valves for RCP cooling water — partially covered by existing callouts (2014 Q30/Q31 CCW valves; 2015 Sim-e JPM 4KV group buses) but not from UFSAR §5.5.1, which does not enumerate the RCP electrical feed or CCW isolation valve numbers. Checked UFSAR §5.5.1, TS 3/4.4, existing callouts; values exist only in callouts (cited there), not in §5.5.1.
- 003 K4.01 / K5.01 — Minimizing power peaking via RCP flow and the relationship of RCPS flow rate to core operating parameters (quadrant power tilt, imbalance, DNBR, local power density) — these are largely B&W (ICS) / core-physics topics; UFSAR §5.5.1 ties RCP flow to maintaining DNBR > 1.3 (§5.5.1.1, now captured) but does not address power peaking or quadrant tilt. Checked UFSAR §5.5.1, TS 3/4.4, existing callouts; no in-section coverage.
- 003 K4.12 — ICS (BW) integrated control system — not applicable to Salem (Westinghouse 4-loop PWR); no Integrated Control System. No source; topic is a catalog artifact.
- 003 K1.11 / K1.09 — Sound monitoring / loose-parts (LRS) interconnection to the RCP — UFSAR §5.5.1 does not describe RCP sound monitoring; loose-parts monitoring is in UFSAR §5.6.8, not §5.5.1. Checked UFSAR §5.5.1, TS 3/4.4, existing callouts; no in-section coverage.
